## MONITORING & TROUBLESHOOTING

### Watch For in Logs

**Good Signs** ✅:
- `✅ SCREENER COMPLETED SUCCESSFULLY` - Screener worked
- `✅ Briefing loaded: X approved + Y watchlist` - Briefing valid
- `Live feed active for N symbols` - Ready to trade

**Warning Signs** ⚠️:
- `❌ SCREENER FAILED: No stock data fetched` - Network or API issue
- `⚠️  Briefing invalid or missing. Attempting regeneration...` - Unusual, but handled
- `❌ GEMINI API ERROR:` - AI model unavailable, math fallback used

**Critical Signs** ❌:
- `❌ BRIEFING UNAVAILABLE: Cannot enable trading` - System exiting
- `Cannot proceed without valid briefing. Exiting.` - Fatal error

### If System Won't Start

1. Check `alcosoft.log` for which screener step failed (1-6)
2. If step 1: Check internet and Yahoo Finance access
3. If step 3: Check Gemini API key and quota (fallback will be used)
4. If step 6: Check disk space and file permissions
5. Delete `data/session_briefing.json` and retry (forces screener to run)

### If Regeneration Keeps Failing

1. Check that Yahoo Finance API is accessible from your network
2. Verify Gemini API credentials if AI picks are critical
3. Ensure `data/` directory has write permissions
4. Check available disk space (> 1 MB)
